# Método ECHO™ — Black Friday 2026 | Homologação

Esta é uma cópia estática de homologação, independente do construtor visual. **Não é o site oficial**, e o Hero V15 ainda não está homologado nesta cópia.

## Publicação

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Estrutura

- `index.html`: HTML da Missão 001.B, sem alteração comercial ou visual.
- `assets/css/site-original.css`: CSS integral extraído do HTML salvo.
- `assets/css/google-fonts.css`: estilos de fontes do Opera, com arquivos WOFF2 externos.
- `assets/images/`: três imagens originais recuperadas.
- `.nojekyll`: desativa o processamento Jekyll.

## Limites

Links de checkout Kiwify e WhatsApp continuam apontando para ambientes reais; não realizar compra de teste. Páginas legais continuam apontando para a página oficial. A fidelidade ao Hero V15 exige avaliação visual e aprovação do CEO.

Os arquivos brutos originais e seus hashes SHA-256 permanecem preservados **fora deste repositório público**. Nenhuma alteração de copy, preços, oferta, identidade, Hero ou Bloco 02 está autorizada automaticamente.
